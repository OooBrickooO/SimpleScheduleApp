# 为课前提醒设置添加平滑展开动画

我已为“课前提醒”设置页面实现了优雅的二级菜单展开和收起动画。

## 变更亮点

### 1. 分级动画逻辑
- **一级展开**：勾选“启用上课提醒”后，提前时间、通知控制等核心设置项现在会平滑地垂直滑动并淡入。
- **二级嵌套展开**：在提醒已启用的基础上，勾选“显示通知栏提醒”会平滑地展开“使用实时通知”子选项。

### 2. 实现技术细节
- **AnimatedVisibility**：利用 Compose 的 `AnimatedVisibility` 组件，配合 `expandVertically()` 和 `shrinkVertically()` 实现自然的物理拉伸感。
- **渐变过渡**：同时叠加了 `fadeIn()` 和 `fadeOut()` 动画，使菜单项在出现和消失时更加轻盈，不会突兀地闪现。

### 3. 布局稳定性
- 动画逻辑已完美集成到现有的 `LazyColumn` 布局中，展开过程会自动推开下方内容，保持列表的连贯性。

## 如何验证
1. 前往 **管理 -> 课前提醒**。
2. 尝试点击 **“启用上课提醒”** 的复选框，观察下方的设置卡片是否丝滑展开。
3. 在启用提醒后，点击 **“显示通知栏提醒”**，观察其下方的子项是否同样平滑展开。
4. 反复点击以确认收起动画同样流畅喵！
